# Smart Card Clustering System Using Unsupervised Learning

## Project Overview

The Smart Card Clustering System is a Machine Learning project that uses Unsupervised Learning techniques to identify patterns and group similar records in a dataset.

The project focuses on analyzing smart card data and discovering meaningful clusters based on the available features.
